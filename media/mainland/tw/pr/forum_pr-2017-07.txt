※ 引述《TenbeensWu (佐久间 薇子)》之铭言： : 1945年开始，西北太平洋台风开始有了自己的名称， : 如果要针对个个命名表的年代进行分期，大致上薇子会这样分： : －1944（无名时期）：即使气象史早在19世纪下半叶的时候， : 就已经有对台风的路径记录，但当时的台风无名称。 : 1945－1948（第一世代）：1945年，美国海军组建JTWC的前身－－ : 台风追踪中心（Typhoon Tracking Center，简称TTC）， : 著手对西北太平洋台风的命名与追踪工作。 : 虽制定名称表，但无「轮回性」，且要够幸运才能被命名， : 例如1945年日本的「阿久根台风」就是典型的遗珠之憾。 : 以1945年为例，当年台风以A开头之名称为起始（A－M）， : 与以N开头之名称为起始（N－Y）轮流交错出现 : （例如：台风名称用到G之后，突然跳到从R开始命名， : 几周后台风T消散，又跳回从H开始，周而复始）； : 1946年开始改善此现象，名称之英文字母开头不再交错出现， : 但命名表似乎也是一次性的，用完就再制定新的名称表。 : 1948－1978（第二世代）：1948年12月，TTC首次使用了有轮回性之台风名称表， : 一用就是卅年有余，使用至第十轮第一组（温妮）结束为止。 : 同样也是按照英文字母开头顺序排列出现， : 有四组女性名，每组廿一个（排除Q、U、X、Y、Z）， : 共计八十四个，台湾、香港、澳门均沿用并中文翻译该名称。 : 使用初期，每年可除名五个以上，以1949年之十个至多， : 后来联合台风警报中心（JTWC）于1959年5月正式成立后， : 开始收敛其除名频率。 : 1979－1989（第三世代）：由于美国女权运动兴起，政治舆论高涨产生压力， : 促使JTWC重新制定命名表，期间沿用十年有余， : 使用至第三轮第一组（韦恩）结束为止。 : 虽同样以按照英文字母开头顺序排列， : 每组廿一个（排除Q、U、X、Y、Z），有四组，共八十四个， : 但男女名称交错轮流出现，台风强悍从此不再只有女性形象。 : 第三世代也保有第二世代的名称，甚至出现原被除名的名称， : 综观而言，除名频率较第二世代频繁。 : 1989－1995（第四世代）：由于使用多年，JTWC开始重新制定台风名称表，使用近七年， : 使用至第三轮丹恩结束为止，当时第一组名称仍未使用完毕， : 第五世代直接于1996年开始，第四世代就此猝然结束。 : 同样是按照英文字母开头顺序排列出现，四组男女名称交错， : 每组廿三个（排除Q、U、X），共九十二个。 : 第四世代也保有第二、三世代的名称， : 综观而言，除名频率仍较第二世代频繁。 : 1996－1999（第五世代）：JTWC又开始重新制定台风名称表，使用四年， : 使用至第二轮丹恩结束为止，当时第一组名称仍未使用完毕， : 第六世代直接于2000年开始，第五世代就此猝然结束。 : 同样按照英文字母开头顺序排列出现， : 每组廿三个（排除Q、U、X），共九十二个， : 即使男女名称未交错出现，两者比例仍占各半。 : 第五世代无除名。 : 2000－ 第六世代）：1998年12月，WMO于菲律宾马尼拉召开第31届台风委员会决议， : 自2000年开始，改由14个国家或地区以其地方特色进行命名， : 一组二个国家或地区，排列顺序为会员国英文名称字母顺序， : 每组廿八个名称，有五组，即各国或地区提供十个名称， : 共计一百四十个，由美国气象机构之命名时期就此结束。 : 第六世代是目前为止，除名频率最为频繁的时期， : 珍贵白海豚 春节期间现身深圳海域

珍贵的中华白海豚在春节期间现身于中国大陆深圳市附近海域，且有3条在海上「闹新春」。

广州日报今天报导，蛇口海事局海巡执法支队支队长宫福忠昨天说，年三十上午，在内伶仃岛以东妈湾液货船锚地附近水域，确实发现了3条白海豚。

宫福忠说，大年三十上午10时30分，他们正常按计画巡航时发现了3条白海豚，它们跟著海巡船20多分钟。

他们把白海豚在海中嬉戏的画面拍摄了下来。

他说，他们在巡航时见过好多次白海豚，但是游到这么近、比较靠近港口海域还是第一次。

另据报导，有市民拍摄到3条白海豚在蛇口邮轮码头附近海域嬉戏，且看来是「一家三口」，2条成年豚和一条幼豚。

白海豚在广东一带备受保护。在香港，港府在白海豚生活水域进行的各项建设，包括港珠澳大桥，都会考虑到对白水豚生活环境的影响。

香港的一些环保组织也定期公布白海豚的情况，监视白水豚的生活环境是否受破坏。
