1. 百度 APP -  (西部陆海大通道崛起 钦州蝶变展新颜) 2020-09-26 湘湘爱旅行   湘湘爱旅行

-----------------------------------------------------------------------------

文字快照 :https://baijiahao.baidu.com/s?id=1678891256292085579

钦州的美名，在人们的记忆中主要体现在八寨沟、三娘湾等自然景观，体现在对中华白海豚的保护，体现在民族风情等等。而在“一带一路”倡议提出以来，这里迅速蝶变，华丽转型，成为了西部陆海新通道的枢纽。

铁路畅通助力钦州发展。“一带一路”陆上部分就是以铁路为轴线展开，在“一带一路”倡议提出之前，钦州确实只能算“铁网末梢”，而随著西部陆海大通道的建设，钦州很快转变为面向东盟的区域铁路枢纽。它是西部陆海大通道上面向东盟的出海口，是陆转海的衔接点，是释放“海”的潜力、打造向海经济的国际门户港。

而今钦州很忙，海面上，轮船鸣笛起伏，轨道上，火车不停穿梭。陆路由铁路将大宗货物运来，海上由货轮将货物运来，钦州以港口、码头、场站等基础设施建设的拓展升级改造，海铁联运手段的运用，打通了海铁联运“最后一公里”。而今，钦州成为全国唯一拥有铁路集装箱中心站的非省会、非计划单列城市，短短几年，钦州港从一个“万吨小港”发展为“亿吨大港”。

为积极构建高效多式联运集疏运体系和现代航运服务体系，深化“国际贸易单一窗口”应用，钦州探索海铁联运集装箱全生命周期管理服务新模式，不断减少通关环节和时间，降低成本，提高效率。目前，钦州港开通了钦州港至重庆、成都、昆明、贵阳、兰州等7条常态化海铁联运班列，其中钦州港至重庆、成都班列实现“天天班”。开通集装箱航线47条，其中外贸航线27条，钦州港至中国香港以及新加坡两个“天天班”实现常态化运营，货物可通达71个国家、地区，155个港口。

钦州港从一个“万吨小港”到“亿吨大港”，展现了西部陆海大通道的华丽崛起，相信钦州还将继续为“一带一路”建设贡献自己的力量，展现出无限发展潜力。(苏纪云)

2. 百度 APP -  (十一自驾不去新疆,还能去哪?) 2020-09-26 Tommy心旅游   Tommy心旅游

十一自驾不去新疆，还能去哪？大半个中国的旅行者都（打算）奔赴新疆开啔一趟秋日之旅，如果没赶上这趟车，那LP给你推荐点不一样的~

两条自驾路线，将顶级中国山河湖海绝景一网打尽，还有顶级美食相伴……握紧方向盘，和LP一起出发！

- 福建沿海线 -

12～15天，1200公里

眀湖水 / 图虫创意

在福建沿海，最令人震撼的莫过于人们对自然与神明的虔诚，数不清的宗教与神祗在这一方土地和谐共处，传统的中原文化在这里找到土壤，而自然风景也因此美得清新脱俗。如果你偏爱“老味道”，大可去漳州泉州寻找正宗的闽南味，而厦门则是古老与时尚结合的最佳产物。

由LonelyPlanet《中国自驾》指南提供

如果你偏爱海的无垠，就去东山岛、六鳌、平潭、三都澳与霞浦吧，大概能够满足一切你对海的想象。如果你嗜吃如命，沿海那些小吃与海鲜会让你担心胃的容量不足。最后你还可以去妈祖的诞生地湄洲岛，许下一个虔诚的心愿。

新能源 / 图虫创意

一条G15沈海高速，几乎串起了福建沿海线的所有城市，只是不免有些单调。福州以南的沿海线大可多走一些非高速的路段；而福州向北，山区开始增多，高速又成为安全便捷的选择。

- 路线亮点 -

- 东 山 岛 -

阿风 / 图虫创意

2014年电影《左耳》在此拍摄，让东山小岛彻底火了一把，“算了Bar”“天一中学”“顶街”，这些电影中的场景很容易就能在这里找到。游玩岛屿则基本以东北角的铜陵镇为据点，东山风动石景区的主角是一块200吨的巨石，传说风吹即动，人力也能晃动，但曾经的日军船舰拖断铁索却未能搬动，7.5级地震也仍旧安然无恙。

VincentHuang / 图虫创意

景区最北边的铜山古城，因目前只留有一段城墙而少有人问津。景区内的关帝庙已有600多年的历史，是明代的一座小庙几经扩建重修而来的。从景区西门广场的轮渡码头，可搭船前往东门屿，岛上最高处有一座建于明代的七层石塔文峰塔，在此可以眺望对岸的海湾。

ic / 图虫创意

铜陵镇的南门湾，是《左耳》中沙滩戏的主要拍摄地。明星沙滩马銮湾紧邻其南，游乐项目众多，夏季人满为患，物价也比铜陵贵出许多。7公里外的金銮湾，客流相对稀少，水质也更清。若想寻觅一处僻静之地，跑一趟乌礁湾的渔村，能让你见识海湾的另一面。由北向南，沙滩的面积依次增加，游客数量却逐个递减。

大光圈975 / 图虫创意

- 六 鳌 -

祥梓 / 图虫创意

六鳌位于漳州以南，在这个宽仅5公里、长不过14公里的半岛上，古城、沙滩、海浪、风车景观相映成趣。最著名的六鳌抽象画廊（六鳌镇农场东侧；免费）位于六鳌半岛新厝村迎海的沙滩上，沙色的巨岩在海风的长年雕琢之下，呈现出精美绝伦的纹理。沿海是一整排高大的风车。

舞影972 / 图虫创意

不需要滤镜，随手一拍即是大片，有不少新人专程来此拍婚纱照。这里也是六鳌半岛上看日出的最佳位置。驱车继续往南来到翡翠湾（六鳌半岛中部东侧；免费），巨大的弧形海滩白沙细腻，沙滩显得格外平整结实，即使在上面骑自行车也不会深陷沙中。

舞影972 / 图虫创意

- 漳 州 -

挖哈 / 图虫创意

作为台湾小吃的源头，对于这个“鱼米花果之乡”，你一定要花点时间去吃懂它。漳州的“古早味”依然低调而倔强地藏在巷子深处的破旧小店，秉承著“有食有行气，有烧香有保庇”的信条。在市区寻觅美食，明清古街区是不二之选，钟法路就可以让你吃不停，古街区内上百年的老房子中，还藏著一些同样资深的“老字号”。漳州文庙是明清古街里最老的建筑，始建于宋代，也是市区里现存的最大古建筑群。

爱的Clover / 图虫创意

而漳州人说起八卦楼威镇阁，就好比在杭州提起雷峰塔一样家喻户晓。继续逛古街，可以在曾是漳州城市中轴线的香港路淘一些手工艺品，走访两座最具代表性的明代石牌坊三世宰贰坊和尚书探花坊。另一侧，电影《云水谣》中取景为台湾市景的台湾路也值得走走，老字号的药店和国粹博物馆点缀其间。

- 鼓 浪 屿 -

folker / 图虫创意

“万国租界”的身份让鼓浪屿成为了名副其实的“万国建筑博物馆”，因为开发较早，大量的咖啡馆、手工品小店、流浪艺人演出以及悠闲的生活态度，让鼓浪屿早早就成了文艺小清新的代名词。

ic / 图虫创意

人气爆棚的同时伴随著大量商家的拥入，导游争相拉客，在高峰期寸步难行，好在琴岛依然有游人甚少踏足的景点和宁静的时刻。

Image by HelloRF Zcool/Shutterstock

旅行者可买鼓浪屿核心景点联票100元，包含岛上的制高点日光岩，中国式园林建筑的海上经典菽庄花园，有郑成功塑像的皓月园，红顶八卦楼风琴博物馆和国际刻字馆，联票仅限当天使用。除了联票内包含的景点，还有海天堂构值得一观，海天堂构正中的主体建筑38号别墅，被开发为“万国建筑博览馆”，陈列著鼓浪屿百年前的生活用具和老照片。

- 厦 门 岛 -

不愿透露姓名的温同学 / 图虫创意

中国少有城市如厦门这般精致，而环岛路充分展示了厦门作为海岛休闲城市的优势所在，舒适的步行道和自行车道沿海岸线的自然形状修建，布满热带花卉的绿化带如同巨大的海边花园。在环岛路开车的时候，可以把车停下，步行或骑行一段才能感受这里的独特魅力。

习木 / 图虫创意

从厦门大学白城海滩开始，沿环岛路海滨步道（免费）充分体验厦门海岸线之美。这段滨海步道蜿蜒6公里多，沿途会经过载入了吉尼斯世界纪录的胡里山炮台，以及书法广场、曾厝埯浴场、音乐广场、白石炮台遗址、太阳湾浴场等。离开步道，可以去环岛路北侧的全国“最文艺的村庄”曾厝埯转悠一下，厝内西餐馆、客栈、酒吧林立，如同翻版的鼓浪屿。

Jinward.qq.com / deposit / 图虫创意

继续沿环岛路行驶，位于东南角的黄厝（免费；全天开放）拥有也许是目前整条路上最干净的海滩了。往前走不多远就到了“一国两制，统一中国”的大标语牌，和海峡对岸小金门岛上“三民主义，统一中国”的标语牌遥相呼应，也是环岛路的标志点之一。

Jasonvision / 图虫创意

继续向北，途经前埔会展中心前往观音山，这里有一片优质的沙滩，夏季的时候会举办白海豚沙滩音乐节和沙雕艺术展，还有一个水上乐园和游乐场，一些餐厅和酒吧供旅行者游玩和歇脚。再往前，邻近环岛路北段的五缘湾和湿地公园是海上运动中心，户外俱乐部提供的帆船和皮划艇体验课程非常适合旅行者。

- 泉 州 -

李平安 / 图虫创意

作为古时海上丝绸之路的起点，泉州成为“东方第一大港”时，旁边的厦门还不过是个小渔村。北宋时期的泉州，已经与海外58个国家有贸易往来，各路“神仙”纷至沓来，以致各种宗教在鲤城内生根发芽然后发展壮大。泉州的老城区并不是刻意做出来的古城，而是实实在在的原汁原味，老街纵横，庙宇林立。

在野步 / 图虫创意

了解泉州可以从泉州博物馆开始，有“泉州历史文化”“泉州南音，戏曲艺术”等基本陈列。隔壁的闽台缘博物馆却是泉州最值得一看的博物馆，从地理、民族、政治、经济、宗教、艺术等各个角度介绍泉州，也包括大陆（福建）与宝岛台湾的历史关系。而这里离泉州之源清源山已经不远，可从朝天门走泉山路转入花博路，沿旅游公路直通南台岩，在山顶泡一壶茶，俯瞰泉州全貌。徒步上山的话，可沿途去看虎乳泉、老君岩、弘一大师舍利塔、泪墨画以及历代摩崖石刻。

时光拾影 / 图虫创意

下山后沿少林路前往泉州少林寺，武魁泉州少林早上10:00是武僧习武的时间，可来到演武厅看现场武术表演。沿刺桐北路向南去往海外交通史博物馆，它绝不像名字听起来那么无聊，更像是关于泉州逸闻的百科全书。接著一路向东，来到海边的蟳埔渔村（东海社区；免费），看福建三大渔女之一的蟳埔女，“戴簪花圈，插象牙筷”的头饰是众多长镜头的焦点。

健忘的行摄世界 / 由图虫提供

- 湄 洲 岛 -

helloiax / 图虫创意

湄洲岛以妈祖故乡而闻名于世，每年都有无数信徒从世界各地来到这个传说中的“东方麦加”。下船后，随著人群前进的路线，登上妈祖祖庙，庙内有妈祖寝殿、圣父母祠、妈祖升天处、宋代妈祖金身等珍贵历史古迹和文物，香火非常旺盛。而旁边的妈祖文化园另外收费，它以山顶妈祖石雕巨像为中轴线起点，兴建了一组仿宋妈祖庙建筑群。

陈小羊timeline / 图虫创意

穿过祖庙群是妈祖碑林，从这里往下可以走到湄屿潮音。沿湄洲大道向南不远处来到天妃故里遗址公园（湄洲岛上林村），公园所在的上林村是妈祖林默娘出生地，目前还保存有明代“天妃故里”石碑等与妈祖有关的遗迹。

- 平 潭 -

阳九 / 图虫创意

沿福建海岸线旅行，见过了各种岛屿和沙滩，到了平潭，仍然还会为大海的辽阔心动。海坛岛上曲折蜿蜒的海岸线有长达100多公里的洁白沙滩，而周边大大小小100多个岛屿上，遍布著各种造型奇特的海蚀地貌。

Jackie_Xu / 图虫创意

我们推荐海岛上的龙凤头沙滩和坛南湾沙滩，距县城近，而且水质清澈，大排档和水上活动也丰富。曾有人在坛南湾海滩上拍摄到了美丽的“蓝眼泪”，那是深海的介形虫在此聚集发出的梦幻蓝光，旅行者们大可去碰碰运气。

阳九 / 图虫创意

位于海岛东南角的将军山是全岛最南端的一处海蚀地貌，有著穿过乱石就身处悬崖的惊心动魄。而位于东北角的东海仙境是难得的观潮好去处，里面的天然海蚀洞在涨潮时声如洪钟。最后，来到西北角的石牌洋，这里有两座巨大的海蚀柱，形似船帆耸立海面，是公认的平潭岛标志。

赵高翔_MoorWorld / 图虫创意

那些散落在海湾与半山之上的石头厝是平潭岛上的另一个特色，这些用火山岩和花岗岩修筑的石头房子，已经成为摄影爱好者追逐的目标。我们推荐流水镇东美村、北厝镇东壁村、中楼镇杨梅坑村与白青乡白胜村这几个特色村落。岛上道路通往各个景点，路况良好，指示牌非常清晰。

- 福 州 -

陈小羊timeline / 图虫创意

有“榕城”别称的福州生活气息浓郁，对福州的探索可以从三坊七巷开始，一条南后街能满足大多数旅行者一站式的吃喝娱购，而深藏于两侧的坊巷更加曲径通幽，这里的里坊格局、明清建筑以及无数近代名人故居，才真正隐藏著老福州的魂魄。例如福州人林则徐次子的林聪彝故居就被辟为福州漆器博物馆，可欣赏“福州三宝”之一的脱胎漆器和漆画。而古典园林式祠堂建筑风格的林则徐纪念馆就在南后街南侧不远处。

ztlyj / 图虫创意

福州的寺庙众多，不妨忘掉它们身上的宗教意味，纯为休闲而来。顶著“福州五大禅林之一”的头衔的西禅寺豪华大气。而隐身闹市的开元寺则是福州现存最古老的寺院，也是日本和印度高僧在唐代的修学之地。严格来说，华林寺不再是一座寺庙，但仅一座珍贵的唐风宋代木构大殿，就绝对值得你跑一趟。

ic / 图虫创意

如果想对福建和福州多些了解的话，就要去福建博物院与福州市博物馆走走，它们会告诉你仓山区的烟台山如何成为了“万国建筑博物馆”，以及这座城市曾经的辉煌和伤痛。

霞浦

光明影像 / 图虫创意

摄影在霞浦也许是最为重要的一个主题，在这里超过400公里的海岸线上，渔民们把海洋当作田地一般来耕作。滩涂中的海带和紫菜田、成片的竹竿和渔网、星星点点的海岛和渔船、面朝大海立在悬崖上的小村庄，都能成为摄影师镜头对准的目标。

离市区不远的北岐滩涂（霞浦北岐村；免费）可能是匆忙的旅行者最好的选择。从霞浦东侧出城，沿福宁大道去往北岐村，大约5公里。在景区前坪停好车后，顺新修的山道往上走，即可找到好的摄影角度，山崖下就是滩涂和紫菜架，远远望去，穿梭往来的船只与此情此景光影交错，浑然一体。

北岐适合拍摄日出，如果拍摄日落，则要去对岸的古岭下村和后歧村。自驾东线终点的大嵛山岛名列“中国最美的十大海岛”，海岛上半米高的牧草已是难得的自然奇观，再加上“岛在海中央、湖在岛中央”的错乱迷离，引得无数背包客翻山越海而来。大部分上岛的人都会选择在天湖边的帐篷区（游客中心一侧的山顶）露营，看日出日落。

若说川西只是川藏线的补充，实在是大大低估了这条坐拥“蜀山之王”贡嘎、“蜀山之后”四姑娘山，以及无数海子、藏寨、寺庙的自驾环线。从雪山冰川到峡谷草甸，这里几乎覆盖了所有藏区景色，而点缀其中的民族村落更为迷人。刚完成道路升级的350国道和铺设一新的212省道让旅程更加惬意。而在“村村通”工程尚未竣工的乡野之中，你还能找到最后的越野乐趣。

四姑娘山国家地质公园包含从西往东的“三沟一山”。名副其实的海子沟深藏著一个个清澈的海子，入沟后沿著山脊行走，抬头就是“姑娘”的芳容 。

开发成熟的长坪沟是更普遍的选择。进沟后乘观光车可至喇嘛寺，然后沿栈道步行，途经枯树滩直至栈道尽头。之后可换马匹继续前往红石滩和木骡子(3800米)。距镇7公里的双桥沟游览起来更为轻松，观光车贯穿首尾。虽然看不见四姑娘山，但周遭各种奇形怪状的雪山也颇为有趣。

>>行驶路上

如果说“最美的风景在路上”，那丹巴到八美的公路则给出了这句话最好的诠释之一。开始的一段穿过有“天然盆景”之称的牦牛穀全长约40公里，深秋时节能看到漫山彩林。峡谷之上是顶果山，可远眺雪山、拜访本教的拥忠彭措岭寺。

继续向前，途经一片遍布鲜红卵石的红石滩，可在热水塘温泉泡个澡缓解疲倦。驶出山谷后盘山而上，至二道班处可见锋利的雅拉雪山惊现眼前，之后一路爬升至海拔4000米的疙瘩梁子。下山路途经惠远寺，之后便可见一片高山草甸景色扑面而来。整段路不到90公里，却足足可以玩上半天。

topsail / 图虫创意

- 塔 公 -

AKA阿佟木 / 图虫创意

AKA阿佟木 / 图虫创意

如果想拍摄雅拉雪山映衬下的日照金顶，一定要在下午4点前赶到，否则阳光就会被背后的雪山挡住。

王德琼 / 图虫创意

最佳的拍摄点位于旁边的塔公草原内，入内10元/人，如果还想深入草原一探，可在金塔前租马(100元/次)。

哎_额哈哈哈哈 / 图虫创意

大概是过往车辆扬起了太多尘土，这座交通重镇显得有些灰头土脸。这里更多是充当进出藏区的中转站，镇中心的餐馆、客栈没有太多特色，设施也普遍老旧。

ic / 图虫创意

相比之下，东边2公里处瓦泽乡(营管藏寨)的景致就好了许多，旅店较新，大都配有餐厅，可解决三餐。乡内北侧小山上设有贡嘎雪山观景台(门票10元)，可远眺雪山。不过能看到贡嘎的地方很多，不必拘泥于此。

- 贡 嘎 -

Lbin-katsura / 图虫创意

作为“蜀山之王”，海拔7556米的贡嘎山是川藏南线上朝觐雪山的不二之选。除了主峰之外，如小贡嘎、嘉子峰、日乌且峰等众多6000米级的雪山众星捧月，别具魅力。而眺望群峰位置最好的且可以自驾到达的莫过于雅哈、子梅两个垭口。

极美faye / 图虫创意

除此之外，沿途的泉华滩(门票25元)、贡嘎寺(门票20元)、巴望海、莲花湖都有迷人的景色。如果需要过夜，在贡嘎山乡、上木居、子梅村都有一些条件一般的民宿。山区周边只有新都桥和沙德有加油站，进山前一定要加满油。

ic / 图虫创意

九龙的繁华程度绝对会让你为之一叹，仿佛不再身处藏区。不大的县城干净整洁，中心广场上藏、彝、汉的雕塑示意著这里是“藏彝走廊”。距九龙24公里的伍须海(门票旺季60元，淡季40元)是一片湖光山色，风光在甘孜州算得上头等，不论是登高俯瞰海子，还是在雪山脚下欣赏瀑布、泡野温泉，都不会令人失望。

　33、<鼹鼠的故事>

　　鼹鼠的故事是捷克非常著名的动画片，当时捷克还未独立和斯洛伐克并称为“捷克和斯洛伐克联邦共和国”，“捷克斯洛伐克”--是我儿时记得的第一个最长的国家名。“鼹鼠”一词在捷克文里拼作“krtek”，在英文中是“mole”。由于鼹鼠善于打洞，现在这个词在媒体报道中已经成了“间谍”的代名词，所以如果你听到说某某国家情报局安全部抓到一只“鼹鼠”可不要真以为他们是抓到了一只打洞的小老鼠哟。

　　《鼹鼠的故事》的出品公司是 “StudioBratrivtriku”，小时候电视台播放的《鼹鼠》系列大都是70年代的作品，有两部90年代出品的短片我是在看VCD时头一见看到。相比之下，我还是喜欢60年代末至80年代初的那些作品，没有太沉重的思想内容，只有轻松可爱就好了。

　　《鼹鼠》系列动画片曾在国际动画节上拿过不少奖项，这是我在一个专门介绍捷克动画产业的网站上看到的，最早的一部《鼹鼠》动画制作于1957年，当时的鼹鼠形象还比较拟人化，没有我们后来熟知的那么憨态可据，而且片中是有对白的，不过当然也听不懂。

　　从60年代中期开始，鼹鼠的形象才固定下来，也就是我们所知道的那个样子。60年代末到80年代初是"鼹鼠"系列的创作巅峰时期，74年和75年则可谓是巅峰的巅峰，总共出品了12部短片，而且部部精彩。要知道，在70年代中期，动画片全部都是手工制作完成的，其中工序之繁杂繁琐和今天是不能同日而语的。进入80年代后，也许是因为受到政局的影响，进程明显放慢下来，整个80年代也不过出品了四部而已，而且其中大多反应了人们对于现代社会资源及环境的忧虑，远不如70年代的轻松悦人。其中1984年出品的《鼹鼠的梦》是一个长片。制作时间距今最近的一部片子是《鼹鼠和青蛙》，制作于2002年。

　　记忆最深刻的一集，是鼹鼠捡到一台坏小子砸坏的汽车，在流水线上修复成一辆崭新的汽车的那集，当时看到汽车一步步的修复，心里面的那份激动，现在回想还能感受的到。

　　真心我们能够重新听到它那独有的“Hello.”

兽。整个过程，游船将行进1500米，穿越四座山峰。　　连州地下河内有无数千姿百态、瑰丽多彩的钟乳石，游览范围共分三层：上中两层为陆地层，厅堂高大宽阔，岩壁坚固，雄伟壮观，“瀑布”“山林”、“幽谷”、“田园”、“瑶寨”，百花争艳，鸟飞云走……；下层是一条地下暗河，由北向南蜿蜒1500米，经过三个美丽的峡谷，穿过四座山头底部，河面宽1.6-10米，水深1-7米，两岸奇景密布，巧夺天工，美不胜收。　　有洞中之宝“金鸡报晓”、“飞象过河”；还有地下河至高至大、一物两景的“寿星公”；更有近百处由石柱、石幔、石笋、石藕、石花等天然形成的奇观，“飞瀑奇石”、“花鸟神阁”……，各处自然美景无不让人叹为观止，乐而忘返。　　“喀斯特现象”给世界许多地方造就了千万奇观。尽管人们已经早就知道石灰岩溶洞像是自然的魔术师，可以变化许多神奇的境界，但是，当我们看到这眼前的景观，使人如入梦境，如登仙域，成了童话里的梦游者，我们仍然会慨叹大自然的造化。洞中有洞、洞中有河、洞中有桥、洞中有瀑布，是连州地下河独有的特色。　　连州地下河于2011年九月正式成为国家5A级景区，我国知名作家秦牧作文章赞曰：“神秘瑰丽的地下河”。现代名作家杨羽说它是“永远没有满足的艺术品”。现代名诗人杨应彬说它“胜似世外桃源”。美丽的连州地下河期待著您的到来！海陵岛大角湾海上丝路旅游区海陵岛大角湾海上丝路旅游区为国家AAAAA级旅游景区、文化旅游景点。　　海陵岛大角湾海上丝路旅游区，位于广东省阳江市海陵岛闸坡镇内，属亚热带季风气候。闸坡海陵岛　　主要景点有大角湾、马尾岛、闸坡海市。它是集海泳、度假、食海鲜、购海味于一体的综合型滨海旅游区，是国家AAAAA级旅游景区。　　阳江市闸坡大角湾位于海陵岛闸坡镇东南，三面群峰环抱，面向浩瀚南海，滩长2.5公里，宽100米，因状似牛角，故名“大角湾”，是海陵岛最知名的景点。正所谓山无水不秀，峰无云不媚，湾内风和浪软，峰顶时有云雾缭绕。大角湾阳光明媚灿烂，沙滩均匀松软，海水清澈纯净，空气清新多氧是旅游度假的好去处。　　海陵岛闸波大角湾，面积14.7万平方米，大角湾滩长2.45公里，宽50－60米，螺线形湾似巨大的牛角，故名“大角湾”。大角湾海水湛蓝，沙质洁净，可进行日光浴、海水浴和沙浴。马尾岛位于海陵岛西南端，与闸坡镇山岭相连，海岸线曲折多湾，最长沙环为1公里，三面环海，实为半岛。岛上林荫遍布，沿曲径前行，有巨石列布海滩，或浑圆平整，或突兀峻峭，虎伏狮立，形状奇特。　　岛上有沙滩排球、足球、沙滩牵引伞、沙滩赛马、骆驼沙滩游、激光射击等体育设施，让您尽情享受热情-。大角湾是海陵岛知名度最高的景点，与阳西沙扒月亮湾并称为“姐妹湾”。　　十里银滩位于海陵岛中部，占地总面积6000亩，三面环山，海岸线长达16.5公里，拥有载入大世界吉尼斯之最的十里银滩、我国最大的仿宋建筑群—宋城、民族别墅、银海山庄等景点。　　十里银滩空气清新，沙质洁净均匀，水质清澈透明。设有帆船、游艇、水上垂钓等水上项目以及沙滩排球、足球等体育活动项目，是休闲度假好去处。　　广东海上丝绸之路博物馆（下简称海丝馆）是以“南海I号”宋代古沉船发掘、保护、展示与研究为主题，展现水下考古现场发掘动态演示过程的世界首个水下考古专题博物馆，是国内首家将宋代沉船水下考古现场发掘向观众开放，高起点打造的动态博物馆，是广东省建设文化大省的重点文化项目之一。　　海丝馆坐落于广东省阳江市海陵岛十里银滩，背山面海，建筑特色鲜明，紧扣海洋文化主题，是海陵岛的地标性建筑。主馆占地面积12288平方米，建筑面积19409平方米，立面由五个大小不一的椭圆体连环相扣组成，整体既似起伏的波浪，又如展翅的海鸥；建筑风格上，干栏式结构融入了古代造船的龙骨结构，具有浓厚的海洋文化色彩。　　馆内基本陈列面积达一万多平方米，分为七大主题展区，分别：扬帆、沉没、探秘、出水、价值、遗珍、成果。基本陈列主要展出“南海I号”数十种珍贵文物，包括充满异域风情的黄金饰品，朴素典雅的中国陶瓷，极其罕见的宋代漆器等。展区内的水晶宫向公众开放“南海I号”发掘现场，观众可近距离地观看考古学家发掘“南海I号”全过程；通过展厅内声光电多媒体场景，体验“南海I号”出帆远洋，搏击风浪和货通万国的浪漫故事，感受古代海上丝路恢宏灿烂的历史。　　目前，广东海上丝绸之路博物馆通过文物展出、文字解说、多媒体演示和场景体验等形式向观众展示了“南海Ⅰ号”的风采。未来我们将不断推出形式更多样、内容更丰富的展览，让游客更多地参与其中，体验南宋时期的文明，体味海洋文化的气息，感受海上航行的乐趣，“南海Ⅰ号”的神秘面纱也将逐步向世人揭开。　　马尾岛是一片未开发的处女湾，沙滩平缓洁净，沙质柔细。大洲上的古灯塔是远航渔船的夜海明灯；小洲上灵日灵庙里的偶像是渔民的保护神。这里水质清澈，水静如 山西北部的白云洞为——马蹄形山谷，它兼收岩泉飞瀑之美，有“胜甲西樵”之称。三峰之间有两飞泉左右迂回而下，称“大云泉”、“小云泉”。泉水折叠汇成了三个湖，即所谓“白云飞下过三湖”：上为“应潮湖”，中为“鉴湖”，下为“会龙湖”。现在其下又增辟“白云”、“人工”两湖，形成五湖飞瀑交辉，亭台山水相映的奇泉。洞山腰的云泉仙馆原是明代的玉楼书院，云泉仙馆西的“三湖书院”门额为林则徐所题，康有为青年时代曾在此面壁苦读三年，山西南部有西天湖和左垂虹瀑，右垂虹瀑等景；山东南部有清暑岩，云岩飞瀑等景，山东北部有全山最大的瀑布玉岩飞瀑，以及玉岩，仙人石，东天湖等景。早在新、旧石器时代，西樵山就有人类活动，留下许多历史遗迹，史学界称为“西樵山文化”。明代中叶成为南国理学名山，至今还保存著白云古寺，以及大量摩崖石刻等文物古迹。惠州西湖惠州西湖为国家级风景名胜区、国家AAAAA级旅游景区。　　惠州西湖是位于中国广东省惠州市境内的一个城市浅水湖泊，是中国国家重点风景名胜区、国家AAAA级旅游景区。其景观由“五湖六桥十八景”组成。在历史上，惠州西湖曾和杭州西湖、颍州西湖合称为中国的三大西湖。　　中国拥有“西湖”之名的景致数不胜数，除了天下闻名的杭州西湖外，惠州西湖也堪称是我国西湖中的个中翘楚。惠州西湖林木茂盛，继承了岭南独树一帜的自然景观特征，与杭州西湖的烟雨江南印象相比，显得更加清爽直白、端庄素雅，因而又有“浓抹杭州惠淡妆”之说。　　惠州西湖的景观由“五湖六桥八景”组成。五湖就是指形成西湖的5个湖区，即菱湖、鳄湖、平湖、丰湖及南湖，逛完所有的湖区至少需要半天的时间。　　平湖是5个湖区中最大的，西湖的主要的核心景点也大多集中在这一带。湖北面环绕著平湖堤，沿著堤坝可参观丰渚园和元妙观，丰渚园很适合夏天来，荷花开得很漂亮。平湖北面的下角东路和下角中路是惠州最老的-区，这里绿树成荫，居民休闲地在湖边打发时光。有点像公园，但是面积挺大，游客也多，里面有一个与陶渊明有关的小山，元妙观到下角的那一段路特别漂亮。泗洲塔泗洲塔　　西湖最有标志性的建筑泗洲塔在平湖西侧，西湖八景“玉塔微澜”中的玉塔指的就是泗洲塔。当年苏东坡寓居惠州时，在其著名的《江月》诗中对湖光塔影有精彩的描绘：“一更山吐月，玉塔卧微澜，正似西湖上，涌金门外看。”玉塔微澜一景由此流传至今。　　孤山在平湖西侧，山上建有苏东坡纪念馆，这也是八景中的“孤山苏迹”所指。孤山山脚有一段九曲桥，与点翠洲相连接，点翠洲上有一座留丹亭，取留取丹心照汗青之意，为纪念辛亥革命中战死的惠州烈士而建立。这些合起来就是八景中的“丹心点翠”。百花洲　　点翠洲北面有一座小桥通往芳华洲和荷花亭，夏天的时候这里常常聚集著一大群摄影爱好者捕捉荷塘景色。　　景区内有5处游艇码头，东大门、九曲桥、芳华洲附近都有，可以在码头租船游湖。这里的湖够大，划船和电动船都有，价格大约为划船30-40元一小时，电动船60元半小时，具体以景区报价为准。如果租电动船，记得租电比较足的船，晚泛舟看斜阳，很美！元妙观　　逛完西湖，正门对面就是惠州的步行街了，也可以去逛下。　　景观“五湖六桥十八景”准提寺　　五湖：平湖、丰湖、南湖、菱湖、鳄湖留丹亭　　平湖：位于西湖的北部。北有拱北桥与东江相通；南有苏堤为平、丰两湖之界；西至孤山、准提阁；西北至桃花溪，东与城区相连。　　丰湖：是北宋时期对惠州西湖的泛称，后来的丰湖是指形成五湖后，在平湖以南，南湖以北的水域及其有关山地界域而言。东坡纪念馆　　鳄湖：位于平湖西北，东至烟霞堤，西至新村观榜桥，南至凤山，北至白鹤含书。东坡纪念馆　　南湖：自古以来山丘、洲渚交错，湖湾深幽曲折，犹如四通八达的水乡，环境优美。现湖区北到圆通桥，南到市一中一带，东枕长寿路、西衔飞鹅岭。点翠洲　　菱湖：位于平湖北，西湖的最大水源——横槎溪，由半径、游塘经游龙山西北注入菱湖。游人泛舟溯湖而上，弯环曲折，可至杜田、半径。九曲桥九曲桥　　六桥：西新桥、拱北桥、烟霞桥、迎仙桥、明圣桥、圆通桥六如亭　　西新桥：位于苏堤中段，为六还中的第一桥。今桥重修于1983年，全桥用花岗岩石砌成，桥呈弧形，5个桥洞大小不一，游艇经此，可往来于平湖与丰湖间。朝云墓　　拱北桥：俗称五眼桥，位于平湖北，是六桥中的第二桥。宋惠州太守陈称围湖筑堤时修建，距今已有900多年的历史。既是惠州千年官道的桥梁，又是西湖泄洪东江的通道。1925年东征时，黄埔军校师生经此桥攻打惠州北门。现桥头建有黄埔军校东征阵亡烈士纪念碑。景贤祠　　烟霞桥：是西湖六桥之一，位于烟霞堤坝北段，连通平湖、鳄湖。据史志载，桥始修于明丙寅年（1626年），后累重修。近代乡贤张友仁增修桥台宽六尺，而桥未改建。八十年代重修，用青石雕刻砌成，刻工极为精美。孤山　　迎仙桥：位于平湖西北，始建于宋代，为六桥中的第四桥。经此，平湖连通市区下角。修竹廓　　明圣桥：又称黄塘桥，在陈公堤中，为惠州西湖著名六桥中第五桥。在北宋陈太守筑堤时同建，当时为石门木桥，明改为石桥，民国又将桥孔改高可通游艇。解放后政府两次修建。现在上可通车，下可通船。杯酒亭杯酒亭　　圆通桥：是西湖著名六桥中第六桥，明正德中惠州知府甘公亮始建，南湖与丰湖以此为界域。历代几经废兴。新中国成立后，于1969年和1983年两次修建。现除原旧桥外，在东侧湖面上新建一桥，与旧桥合为圆通双桥。丰渚园　　十八景：飞鹅览胜、丰山浩气、水帘飞瀑、平湖秋月、玉塔微澜、红棉春醉、西新避暑、花洲话雨、花港观鱼、芳华秋艳、苏堤玩月、连理红棉、孤山苏迹、南苑绿絮、烟霞柳浪、留丹点翠、象岭云飞、鹤鹭祥舞丰渚园风浴阁　　丰湖书院　　广州白云山广州白云山为国家级风景名胜区、国家AAAAA级旅游景区、爱国主义教育基地。　　位于广州市北部，是南粤名山之一，被称为“羊城第一秀”，由30多座山峰组成，登高可俯览全市，遥望珠江。每当雨后天晴或暮春时节，山间白云综绕，山名由此得来。　　白云山自古以来就是有名的风景胜地，“蒲润源泉”、“白云晚望”、“景泰归增”等均被列入“羊城八景”。近年来又开辟了山顶和山北公园，修建了庭园式山庄旅舍、双溪别墅、松涛别院及观鸟园。每年的农历9月9日重阳节，会有许多人去登白云山。　　白云山很早就知名于世。战国时已有名士出入，晋朝时已风景宜人，唐朝便以胜地著称。宋代以来的&#34;羊城八景&#34;，白云山就占多处。羊城人们一向喜欢到此登高游览，尤其在九九重阳，更以登白云山为乐事，每逢此时，扶老携幼，人流熙熙攘攘的热闹场景便构成羊城一幅独特的风情画。白云山　　现在，白云山有专线游览车，顺著盘山公路而上迂回曲折，可直达山顶公园和天南第一峰，还设有上山索道。山上有各式风味餐厅和各种服务设施，还有简易炉灶可供人们野餐和烤烧，已成为全国有名的游览胜地。白云山　　白云山上还有高山滑草、1400米滑道、三角滑翔翼等体育娱乐项目.面积：20.98平方公里。　　　　　概貌：白云山由30多座山峰簇集而成，全山面积28平方公里，最高峰摩星岭海拔382米，是广州市最高峰。　　白云山气势磅礴，山峦起伏，沟穀纵横，最高峰为摩星岭，山上道路四通八达。风景优美，名胜古迹甚多。自山北向南分为山北、山顶、麓湖三个风景区。麓湖区内，绿树成荫，湖面平静如镜由麓湖可乘缆车至山项。山顶区包括山顶公园、鸣春穀、山庄旅舍、双溪别墅、能仁寺、九龙泉等。山北风景区则另是一番景象：群山起伏，苍松遍野，一望无际，犹如滔滔大海；山风吹过，其声如涛，此即被誉为羊城八景之一的&#34;白云松涛&#34;。散落在湖光山色和峰峦叠翠间的蒲穀、能仁寺、天南第一峰、鸣春穀、九龙泉、碑林、摩天岭、山湾、双溪、山庄、白云松涛、松涛别院、明珠楼、白云仙馆、聚芳园、麓湖高尔夫球乡村俱乐部、广州溜冰俱乐部、鹿鸣酒家等与新建成的云台花园、雕塑公园、白云滑道等景点。　　举世闻名的华南植物园位于龙眼洞，种植有热带、亚热带植物4500余种，有专供人们观赏的展览区，分别种植棕榈植物、孑遗植物、热带植物、荫生植物、防污绿化植物、经济植物、竹和药用植物、园林树木、裸子植物等。园内还建有人工湖、水榭、接待厅、休息亭、实验楼、荫棚、温室等设施，既是研究开发利用植物资源和普及植物学知识的基地，又是一个丰富多彩、风景如画、绿海芬菲的植物大观园，吸引著众多的游人。丹霞山丹霞山为国家级风景名胜区、国家AAAAA级旅游景区、国家地质公园、科普教育基地、世界自然遗产。　　丹霞山座落于仁化县城南约9公里处，距韶关市区56公里。丹霞山与南海罗浮山、博罗罗浮山、肇庆鼎湖山并列为广东四大名山，1988年被国务院定为国家级风景名胜区。全山均为红色砂砾岩，远眺全山，“色如渥丹，灿若明霞”，因而又有人称之为“红石花园”。它的地质岩层是由碎屑红岩，砾石岩和粉状沙岩所组成，含有钙质，氧化铁和少量石膏，呈丹红色，是砂岩地势的代表。这种地形和福建的武夷山、韶关的金鸡岭等同属丹霞地貌。丹霞山古称烧木佛旧地，又称长老寨。据《广东省通志》记载，丹霞山在残唐五代时期已有佛教居士法云在山上之锦石岩憩。　　丹霞山是广东省四大名山之一，位于粤北仁化县城南九公里处，以“奇，险，美”著称，因“色如渥丹，灿若明霞”而得名。“桂林山水甲天下，不如广东一丹霞。”这是人们对丹霞山的赞美之语。传说，很早以前，有一对青年男女为了寻找一个理想的地方安家立业，骑著一匹枣红色的骏马，乘风驾云。一天，他们来到洞庭湖上，忽见五岭之南，浈水之畔，树绿天碧，奇花似锦，百鸟翔集，彩蝶飞舞，景色甚为美丽，于是策马南行，在一株高若苍天的丹桂树下停了下来。他们被这儿的奇山异水迷住了，于是便在这里安居下来。这匹神马也很留恋这儿，终日畅饮著这儿的澄澈悠悠的江水，年长月久，便化为一座峻秀壮丽的山峦，这山峦便是丹霞山。　　丹霞山在今天的地质学上称为“丹霞地形”。据地质学家的考证，早在二千多万年前，丹霞山一带原是一个巨大的湖泊，后来由于地壳上升，湖身露出地面，岩层受风雨侵蚀，水流冲刷，才变成现在这样的峰林奇观。　　丹霞山上有三个高峰，远看三峰高耸对峙，如出天表，蜿蜒变化。宝峰峙其北，海螺峰居其中，长老峰倚其南，三峰之中又以海螺峰最为雄峻。丹霞山名胜古迹甚多，除了别传寺，锦石岩，海天门，一线天等景外，还有历代文人骚客留下的诗文题刻。那些奇峰妙景，神形仙态，实在令人目不暇接，流连忘返。经济发展历史古代广东经济以其鲜明的特色在全国占有著重要的地位。秦汉时期，南越地区的犀牛角、象牙、翡翠、珠玑等物品成为中原人民喜好的珍品，岭南的水果、矿物、海产品也不断北上与中原其它物产交换。“海上丝绸之路”的开辟，更使广州很早就成为中国沟通东南亚、非洲、欧洲的重要港口。唐宋市舶贸易的繁荣，广东成为朝廷的财富重地，中央王朝十分重视广东在全国的经济地位，广东很早就和中原有经济文化联系，唐代大庾岭通道的开辟，进一步加强了广东和全国的交流。 明中叶以后，广东社会经济更呈现出一派勃勃生机。农业方面，沙田的开发和桑基生态农业的发展，使珠江三角洲成为中国著名的经济作物种植区；手工业方面，佛山的冶铸，佛山石湾的陶瓷，广州一带的丝织业，粤东的制糖等都独步全国，“广货”驰名天下；商业领域，广东商帮周流天下，明清时期大庾岭商路的繁荣是广东经济发展和商业兴盛的标志，乾隆二十二年（1757年）的广州一口通商制度，又使广东成为中国与世界联系的重要省份。此时，广东经济发展已领先全国，珠江三角洲成为中国最富庶的地区。虽然晚清的鸦片输入和帝国主义的入侵给广东的经济发展造成一定的影响，但广东得风气之先，同时也成为中国民族资本主义发展最早和最快的地区之一。
